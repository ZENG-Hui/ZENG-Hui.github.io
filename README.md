# ZENG-Hui.github.io

曾晖的个人主页：<https://zeng-hui.github.io/>

页面上的「小鲸鱼」是替曾晖干活的 AI 助手。整页以第三方口吻介绍他，不假装是他本人在说话。

零依赖静态站点——手写 HTML/CSS/原生 JS，没有构建步骤、没有 npm 包、没有框架。
所有效果都是这一个 canvas 和一个渲染循环。

## 背景那条鲸鱼

`index.html` 里只有一行 `<canvas id="ocean">`。鲸鱼**完全由 0 和 1 两个字符组成**，没有图片、没有字体图标。

### 一、形状从哪来

`assets/js/orca-logo.js` 把 DeepSeek 的 logo 路径当掩膜用：

1. 用 `Path2D` 在「身体坐标」里画一遍 logo 剪影，按 `PPU` 栅格化成位图；
2. 对位图做倒角距离变换，每个点知道自己离轮廓多远；
3. 按固定格距（`cell`）铺格子，落在剪影里的格子放一个 `0` 或 `1`；
4. 亮度由到边缘的距离决定——内部平坦，靠边一圈提亮，于是轮廓是"碎"的而不是硬边。

字不是每帧现画：先烘成两张图集（冷色 / 暖色），之后每帧只是 `drawImage`。这是性能的关键，
约 800 个字，一帧 4–5 ms。

### 二、它怎么动

身体是**刚体**——整条鲸鱼不做正弦波，只有局部在动。这是刻意的：整体波动会让它看起来像一面旗子。

| 部位 | 做法 |
| --- | --- |
| 尾鳍 | 绕尾柄 `(62, -12)` 旋转，幅度 0.22 rad。半径 / 高度 / 横向三道平滑闸限制作用范围，过渡带宽 24–34 单位，保证相邻两个字的位移差 < 半格（不会断开，也不是硬拧） |
| 胸鳍 | 向外凸出的那一块（身体坐标 x 38..62 / y 42..68），随垂直速度上下摆，软权重、无切块 |
| 全身 | 只保留上下浮动 `bob`，没有整体波浪 |
| 看你一眼 | 慢下来时整体等比放大 3%（不是横向压扁） |

### 三、它的一生

`assets/js/ocean.js` 的 `state.mode`：

```
off ──► in ──► swim ──► windup ──► out ──┬─► (掉头) in
                                          └─► off
```

- **off**：黑暗里等 4–10 秒
- **in**：从深海游上来，11.4 秒。1/3 大小起，前 1.8 秒淡入
- **swim**：正常巡游 22–38 秒，13 px/s；每隔 14 秒左右慢下来看你一眼
- **windup**：离开前蓄力——尾鳍 2.1 倍速拍两整下（约 4.1 秒），带 0.45 倍速前冲
- **out**：游回深海，14.25 秒，最后 1.8 秒在远处淡出
- **硬币**：到最远处时有 50% 概率掉头沿原路游回来（方向已反转），否则消失、换个位置再出现

### 四、透视

`in` / `out` / 掉头用的是同一套投影，只有一份：

```js
P0 = 出发位置；V = 远点（沿朝向 vw*0.46 处，贴近地平线）
P(k) = V + (P0 - V) / k      // 屏幕位置
size(k) = 1 / k              // 视角大小，k 从 1 到 3
```

位置和大小由同一个 `k` 驱动，所以平移速度和缩放速度不可能失衡——它们本来就是同一个量的两种表现。
浮出和游走时远点在身后或身前由 `anchor(behind)` 决定，保证鲸鱼**头始终朝前**。


## 离线渲染工具（`tools/lab`）

不想开浏览器就能看效果、也能在没有网络的地方验证行为。跑在 node 里，用的是真的
`assets/js/orca-logo.js` 和 `ocean.js`，不是另写一份。

    cd tools/lab
    npm install            # 只依赖 @napi-rs/canvas
    node tail-phases.mjs   # 尾鳍相位对照 + 相邻字位移差（判断会不会断裂）
    node fin-frames.mjs    # 胸鳍上摆 / 平 / 下摆
    node headings.mjs      # 朝向左右
    node lifecycle.mjs     # 浮起 → 巡游 → 蓄力 → 游远的连拍
    node flow-stats.mjs 20000   # 长跑统计：掉头/消失比例、蓄力拍几下、朝向是否正确

图片输出到 `tools/lab/out/`（已 gitignore）。

`tail-phases.mjs` 末尾会打印「相邻字最大位移差」——超过约半个格子（2.1 单位）就看得出断裂，
调尾鳍幅度或过渡带宽度时以这个数为准。

## 想调整

`ocean.js` 顶部的 `CFG`：

| 键 | 含义 |
| --- | --- |
| `cell` | 身体坐标里的格子边长（越小越密越慢） |
| `swim` | 巡游速度 px/s |
| `lifeMin/lifeMax` | 一次出现待多久 |
| `inSpan/outSpan` | 游近 / 游远时长 |
| `depthFar` | 游到头时离镜头远几倍（3 = 缩到 1/3） |
| `glanceEvery/glanceHold` | 多久看你一眼 / 看多久 |

字形、配色、棋盘格距在 `orca-logo.js` 的 `makeAtlas` / `buildMask` 里。

## 其他约束

- `pointer-events: none`，不挡点击也不参与选中；`z-index: 0`，永远压在正文下面
- 每帧只画字，不触发布局；限到约 35 fps，切后台停 rAF
- `prefers-reduced-motion` 下不游，只静态画一帧
- 出错自己停掉（`try/catch`），不连累页面上别的脚本
